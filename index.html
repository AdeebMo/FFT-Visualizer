1. What FFT Is

FFT is a fast way to compute the DFT

The Fast Fourier Transform (FFT) efficiently computes the discrete Fourier transform, converting coefficients or samples into the frequency domain. In this project we apply FFT to multiply polynomials.

2. Why We Need FFT

Direct multiplication becomes slow as polynomials grow

Directly multiplying two polynomials requires pairing every coefficient with every other coefficient, collecting like terms and therefore grows quadratic in cost.

3. Polynomial Representations

Coefficient form and value form tell the same story in different ways

Coefficient form A(x) = 3 + 2x + x^2 → [3, 2, 1]
Value form [A(x0), A(x1), A(x2), ...]

Two representations: coefficients or values at chosen points. In coefficient form the polynomial is described by its coefficients (e.g., [3, 2, 1]); in value form by its values at selected points.

4. Evaluation And Interpolation

These two ideas connect the two representations

Evaluation computes the polynomial at chosen points; interpolation reconstructs the coefficients from those values. Fast evaluation and interpolation are essential to multiply polynomials using FFT.

5. Roots Of Unity Intuition

FFT becomes fast because it evaluates at special points

FFT evaluates the polynomial at roots of unity - special complex numbers whose symmetry allows splitting and recombining work efficiently.

Formal notation ωn = e-2πi / n
6. DFT Vs FFT

Same goal, different speed

Both DFT and FFT compute the same transform. DFT is O(n^2); FFT uses divide & conquer to reduce work to O(n log n).

7. The Core FFT Idea

Split the input into even and odd parts, then combine later

FFT splits the input into even- and odd-indexed parts, computes smaller transforms, then combines them. Repeating this reduces the total work.

Pipeline

How FFT Multiplies Polynomials

In value form, multiplication becomes pointwise, and inverse FFT brings us back to coefficients.

  1. Start with both polynomials in coefficient form.
  2. Pad both arrays with zeros to a power-of-two length that can hold the product.
  3. Evaluate both padded arrays at roots of unity using FFT.
  4. Multiply the evaluated values pointwise.
  5. Use inverse FFT to return to coefficient form.
