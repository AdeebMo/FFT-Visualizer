Overview

What this tool teaches

This standalone teaching tool focuses on the iterative radix-2 Cooley-Tukey FFT as a circuit. It shows how inputs are first loaded into bit-reversed order, then processed by butterfly layers that apply twiddle factors and update frequency values in place.

  • Bit-reversal first: see why iterative FFT needs a special input order before any butterfly stage begins.
  • Butterfly flow: inspect the exact pair of positions, twiddle factor, and updated upper/lower outputs at every step.
  • Same math as recursion: compare iterative and recursive FFT outputs and confirm they match numerically.
Concept

How the layered circuit works

At stage s, the circuit works on blocks of size 2^s. Each butterfly combines one upper wire and one lower wire using a twiddle factor w = e^(-2pi i j / m), then writes updated outputs back to the same pair of positions.

  1. Load: place the input into bit-reversed order.
  2. Mix: compute t = w * lower for each butterfly.
  3. Update: write upper = u + t and lower = u - t.

Complexity

Why FFT is efficient

A direct Discrete Fourier Transform compares each output frequency against every input sample, which costs O(n^2). FFT reuses symmetry and factorization, so the same transform is built from log2(n) layers of n / 2 butterflies each.

  • Work: n / 2 butterflies per stage times log2(n) stages gives O(n log n).
  • Depth: the circuit has only log2(n) sequential layers.
  • Parallel view: butterflies inside a single stage can run at the same time.

Key Concepts

The ideas students should leave with

The visualization is designed to connect the algebra, the circuit layout, and the runtime advantage.

Butterfly

A butterfly mixes two values at a time, creating the upper and lower outputs that feed the next stage.

Bit Reversal

Reversing binary indices aligns the iterative in-place schedule with the recursive even/odd decomposition.

Twiddle Factors

The complex roots of unity rotate lower-branch values so each stage contributes the correct phase information.

Iterative vs Recursive

The layered circuit is just the recursive FFT reorganized into fixed stages that are easier to implement in hardware.
