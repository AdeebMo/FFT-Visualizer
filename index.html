What Is FFT?

A faster way to compute the Discrete Fourier Transform

The Discrete Fourier Transform, or DFT, turns a list of samples into a list of frequency components. In simple terms, it tells us which repeating patterns are hidden inside the signal.

FFT is not a different answer. It is a much faster way to compute the same DFT by reusing structure instead of recomputing similar work over and over again.

Why FFT Is Important

It shows up anywhere fast frequency analysis or convolution matters

  • Signal processing: analyze sound, images, and communication signals.
  • Polynomial multiplication: turn convolution into fast pointwise multiplication.
  • Efficient computation: solve useful problems much faster than the naive DFT.

That is why FFT is such a common idea in algorithms, engineering, and high-performance computing.

How The Iterative FFT Works

Four ideas drive the whole algorithm

  • Bit-reversal: reorder the input so the iterative schedule matches the recursive split.
  • Butterflies: combine an upper value and a lower value in one local update.
  • Twiddle factors: rotate one branch by the right complex root of unity.
  • Stages: repeat the same pattern on bigger and bigger blocks.
Why The Circuit View Matters

The layered drawing makes the parallel structure obvious

In one stage, many butterflies can run at the same time because they touch different wires. That is why the circuit picture is so useful: it shows FFT as a structured network, not just a loop nest.

  • Parallel butterflies: same-stage work can happen simultaneously.
  • O(log n) depth: only the stage count must happen one after another.
  • Hardware-friendly: the pattern is regular and easy to map to a pipeline or circuit.
Complexity

Why FFT beats the naive DFT

A naive DFT compares every output frequency with every input sample, so the amount of work grows like O(n^2). FFT avoids that full all-to-all comparison by breaking the transform into reusable butterfly stages.

  • Naive DFT: too many repeated calculations.
  • FFT: log2(n) stages with n / 2 butterflies each.
  • Result: much better scaling as the input gets larger.

Pipeline

How FFT Multiplies Polynomials

The FFT view of multiplication treats coefficient convolution as pointwise multiplication after evaluation.

  1. Start with two coefficient lists in ordinary polynomial form.
  2. Pad both lists with zeros to a power-of-two length that can hold the full product.
  3. Evaluate both padded polynomials at roots of unity using FFT.
  4. Multiply the evaluated values pointwise.
  5. Use the inverse FFT to return to coefficient form.

Worked Example

Why both methods agree

For A(x) = 1 + 2x + 3x2 and B(x) = 2 + x, the coefficient convolution is:

Constant term: 1*2 = 2
x term: 1*1 + 2*2 = 5
x2 term: 2*1 + 3*2 = 8
x3 term: 3*1 = 3

So the final product is 2 + 5x + 8x2 + 3x3. FFT reaches the same answer more efficiently by moving into the frequency domain first.
